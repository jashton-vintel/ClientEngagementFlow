# EngagementFlow

EngagementFlow is a small reference application exploring secure,
asynchronous document-processing workflows using ASP.NET Core and Azure.

## Goals

The project demonstrates:

- ASP.NET Core Web APIs
- Microsoft Entra ID authentication
- Azure Service Bus
- background processing
- SignalR real-time notifications
- Azure hosting
- resilience and observability

## Status

Initial architecture and solution setup.
